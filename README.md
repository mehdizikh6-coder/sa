# ربات تلگرامی انتشار بیانیه (Python / Render)

تمام فایل‌های پروژه در ریشه مخزن هستند و هیچ پوشه داخلی برای اجرای ربات لازم نیست.

## فایل‌ها
- `main.py` کد اصلی ربات
- `requirements.txt` وابستگی‌ها
- `render.yaml` تنظیم سرویس Background Worker در Render
- `players.json` فهرست اولیه بازیکنان (از نسخه اصلی منتقل شده)
- `settings.json` وضعیت روشن/خاموش ربات

## راه‌اندازی در GitHub و Render
1. فایل‌های همین پروژه را مستقیماً در ریشه یک GitHub Repository قرار دهید.
2. در Render گزینه **New + → Blueprint** را انتخاب کنید و مخزن را متصل کنید؛ یا یک **Background Worker** بسازید.
3. مقادیر Environment را تنظیم کنید:
   - `TELEGRAM_BOT_TOKEN`: توکن BotFather
   - `ADMIN_ID`: آیدی عددی مالک
   - `CHANNEL_ID`: آیدی کانال مانند `-1001234567890` یا `@channelusername`. فعلاً خالی گذاشتن آن مجاز است، اما تا وقتی تنظیم نشود انتشار انجام نمی‌شود.
4. ربات را در کانال به‌عنوان Administrator اضافه کنید و اجازه ارسال پیام بدهید.
5. Deploy کنید. دستور اجرا `python main.py` است.

## منوی کنار کادر پیام
دستورات `/start`، `/admin` و `/cancel` برای همه کاربران در منوی تلگرام ثبت می‌شوند. بنابراین گزینه پنل مدیریت برای همه قابل مشاهده است؛ ولی تمام callbackهای مدیریتی و فرمان `/admin` در خود برنامه فقط برای `ADMIN_ID` مجاز هستند. نمایش گزینه به معنی دسترسی مدیریتی نیست.

## امکانات
- ثبت، حذف، فهرست و ویرایش کشور بازیکنان توسط مالک
- روشن/خاموش کردن ربات توسط مالک
- دریافت عکس یا ویدیو تا سقف پیش‌فرض ۲ مگابایت
- دریافت متن بیانیه با حداقل ۴ خط و ۴۵ حرف
- پیش‌نمایش و تأیید/رد پیش از انتشار
- درج پرچم و نام کشور و ارسال بیانیه به کانال
- مدیریت خطاها و تلاش مجدد در صورت اختلال موقت شبکه

## اجرای محلی
```bash
python -m pip install -r requirements.txt
# متغیرهای محیطی را در CMD تنظیم کنید:
set TELEGRAM_BOT_TOKEN=توکن
set ADMIN_ID=آیدی_عددی_مالک
set CHANNEL_ID=
python main.py
```

## نکته درباره Web Service رایگان
این نسخه با نوع `web` و پلن `free` تنظیم شده و یک HTTP server روی `0.0.0.0:$PORT` بالا می‌آورد. مسیر `/health` برای بررسی سلامت سرویس است. دریافت آپدیت‌های تلگرام در یک Thread جداگانه با Long Polling انجام می‌شود.

**محدودیت پلن رایگان Render:** سرویس‌های رایگان Web Service پس از حدود ۱۵ دقیقه بدون ترافیک ورودی به حالت خواب می‌روند و در درخواست بعدی با تأخیر بیدار می‌شوند. بنابراین اجرای ۲۴ساعته و بدون وقفه تضمین‌شده نیست؛ در زمان خواب، ربات هم آپدیت‌های تلگرام را پردازش نمی‌کند.

## نکته مهم درباره ذخیره‌سازی در Render
فایل‌های JSON در ریشه پروژه نگهداری می‌شوند، اما فایل‌سیستم سرویس رایگان Render به‌صورت پیش‌فرض دائمی نیست و ممکن است با Deploy یا Restart پاک شود. برای حفظ دائمی بازیکنان و تنظیمات، از دیتابیس خارجی یا فضای ذخیره‌سازی پایدار استفاده کنید. بدون آن، برای جلوگیری از از دست رفتن داده‌ها نسخه پشتیبان از `players.json` و `settings.json` نگه دارید.

## نکات
- فقط یک نمونه از ربات را هم‌زمان اجرا کنید؛ اجرای چند نمونه polling باعث تداخل `getUpdates` می‌شود.
- اگر قبلاً همین توکن روی Railway یا هاست دیگری اجرا بوده، نمونه قبلی را متوقف کنید.
- اگر Telegram خطای 409 داد، یعنی نمونه دیگری با همین توکن در حال دریافت آپدیت است.
